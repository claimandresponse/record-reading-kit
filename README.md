# Claim & Response record reading kit

A worksheet and five source examples for checking what a public record says, who issued it and how it fits into a proceeding. The examples cover an administrative decision, a court press release, an agreement, an order and a judgment.

Start with the [Claim & Response methodology](https://claimandresponse.com/methodology/). Use the [source examples CSV](SourceExamples.csv) to open the original documents and the related archive records.

The [ten record-reading guides](guides/README.md) include transcripts, captions and exercises that use public sources.

## Record worksheet

1. **Identify the matter.** Record the names of the parties, the deciding authority, the case or reference number and the jurisdiction. Keep similarly named people or businesses separate.
2. **Identify the document.** Record the issuer, document title, document type and date. If the date on the cover differs from the date it was filed, keep both with a label. Save a link to the original and the date you checked it.
3. **Attribute the statements.** Keep what a party alleges, what another party replies and what the authority determines in separate fields. Point to the relevant page, paragraph or clause for each.
4. **Check the scope and sequence.** Read what the order actually grants or rejects. Look for later orders and separate proceedings before using a historical record to describe the current position.
5. **Record the gap.** If a document is missing, a link has changed or the latest position is unclear, note which record would answer the question. Keep a dated correction when a published source changes.

## About the examples

The CSV lists selected documents and shows where to look on the page to identify their type. It does not attempt to list every filing or report the current status of any case. The archive links lead to the related matter pages. Each linked document remains subject to its original publisher’s terms.
