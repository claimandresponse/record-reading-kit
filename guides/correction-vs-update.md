# A correction and an update tell different stories

[Watch the captioned guide](https://claimandresponse.com/videos/#correction-vs-update) · [English captions](captions/correction-vs-update.vtt)

## Transcript

If a page gets an existing date wrong, correct the date and show the source.

If a court acts again later, add a new dated entry and update the status.

In both cases, a short public note lets readers see exactly what changed.

## Try it

Write one short note for a misspelled name in a published article. Write a second for a decision issued after the article appeared. Label each note and give the date it would appear.
