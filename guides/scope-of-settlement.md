# What did the settlement cover?

[Watch the captioned guide](https://claimandresponse.com/videos/#scope-of-settlement) · [English captions](captions/scope-of-settlement.vtt)

## Transcript

Find the parties named in the agreement.

Read the scope and release terms to see which claims it resolves.

Read the admission terms and any accompanying order before summarizing the outcome.

## Try it

Open a settlement record from the archive. Copy the parties, covered claims and any admission language into separate fields. Add the relevant clause or page number for each field.
