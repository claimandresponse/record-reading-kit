# How to write a dated list check

[Watch the captioned guide](https://claimandresponse.com/videos/#one-list-one-result) · [English captions](captions/one-list-one-result.vtt)

## Transcript

Record the exact list and the authority that maintains it.

Write down the names and identifiers you searched and the date you searched them.

Describe the result within the scope of that search. Link to the list so readers can check it themselves.

## Try it

Choose an official list linked from the archive. Record its name, the date of your search and the exact names you checked. Describe the result in a sentence limited to that list and date.
